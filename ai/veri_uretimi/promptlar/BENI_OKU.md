# Promptlar

| Dosya | Ne |
| --- | --- |
| `hikaye.txt` | Hikâye promptu ("önce mantık": sorun → yapılan → sonuç) |
| `kart.txt` | Kart promptu. Öğretmen satırlı yazar: Metin / Sol / Sol sonuç / Sol etki / Sağ / Sağ sonuç / Sağ etki |
| `kart_ornekler.json` | 8 örnek kart. `{ornek}` yerine her istekte biri gelir (konuşanla aynı rol seçilmez) |

Kodu değiştirmeden düzeltilebilir. Değiştirirsen yeni tohumla yeni dosya aç (eski dosyaya devam edilmez).
